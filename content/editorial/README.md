# 正式版开发的词卡来源与校审状态

二二十个TSV文件合计600词。原120词和后续180词沿用稳定标识及原始来源版本，本次新增300词来源版本为0.3。中文核心释义、搭配、英汉例句及学习分类为本项目辅助编写的原创草稿，依照上级`LICENSE.md`采用CC BY-SA 4.0。

本次内容由Codex辅助编写；运行环境未提供可归档的精确模型版本，记录为未提供，不虚构模型标识。编辑批次为`editorial-0.3-20261106`，选词记录见`../batches/0.3.0.json`。没有将自动编写或结构检查通过的内容标为人工审核通过。

新增300词均出现在固定ECDICT候选拼写并集中，按来源标签的最低参考层级归类：有zk/gk标签的归基础，其余有cet4的归四级，再其余cet6归六级。TSV保留该参考层级，生成工具再次核对来源。当前600词参考层级为基础452、四级74、六级38及扩展36；0.3.1修订已将全部候选内词卡统一按上述规则分层，未在来源并集出现的36词单列扩展；此前试制参考标签不再使用。

音标采用美音参考写法。live、use、house、frequent、coordinate、legitimate、graduate、subject等同形异音或词性相关读音，在词形栏提示其他读法；生成工具为重点词设置主词性发音。代词I始终大写显示，稳定标识和音频路径仍为小写dl-i、audio/i.wav。完整人工校听仍待进行。

来源候选名单之外的36个旧试用词在`../reports/scope.md`公开列出；正式词库收录前须裁定。拼写和分级候选与词卡正文分开管理，未复制ECDICT的释义、音标、例句或音频。

语义分类保存于`../semantic.json`。独立词可按语境置于同组，该分组不表示共同词源。science词族只保留science与scientific，research、experiment、theory改归独立词；innovation与invent不因语义相近而归为同一词族。

修改原稿后，重新生成内容并运行校对报告。若修改例句文字，须重新制作对应音频并复核，不得只沿用旧WAV。校对清单位于`../reports/card-audit.tsv`，记录词条、层级、目录、分组、来源标签和缺项。

校审工作台通过npm run editorial启动。署名、六项核对结果与依据保存到../reviews.json，数据库及发行检查分别见../../public/lexicon.sqlite与../reports/release.json。应用1.0开发版使用独立内容修订0.3.1和课程范围0.3.0。
