# 正式版开发的词卡来源与校审状态

二十五个TSV文件合计750词。原有630词沿用稳定标识、顺序与原始来源版本；本批120张六级卡的来源版本为0.5。中文核心释义、搭配、英汉例句及学习分类为本项目辅助编写的原创草稿，依照上级`LICENSE.md`采用CC BY-SA 4.0。

本批选词及出处见 [0.5.0批次](../batches/0.5.0.json)：从待制目标中选取120个星号明确的直接词目，逐词保存大纲记录ID。本次由Codex辅助编写，精确模型版本未归档。结构检查和读音抽查不等同于人工审核通过。

当前参考级别结合官方词形索引与基础标签：基础466、四级133、六级138、扩展13。基础标签优先，其余优先采用官方行的级别；附列形式按行继承，保留推定依据。所有同形分列和变体记录均保留，不据拼写相交宣称义项完整。原630张词卡的标识与顺序保留，新批次追加120词。

音标采用美音参考写法。live、use、house、frequent、coordinate、legitimate、graduate、subject等同形异音或词性相关读音，在词形栏提示其他读法；生成工具为重点词设置主词性发音。代词I始终大写显示，稳定标识和音频路径仍为小写dl-i、audio/i.wav。0.5批次采用美音音素规则，并对 excerpt、convict、affiliate、refund 的主词性读音作单独设置。原有音频保留，完整人工校听仍待进行。

当前目标范围外的13张扩展卡在`../reports/scope.md`公开列出；纳入正式必学范围前须裁定。拼写和分级候选与词卡正文分开管理，未复制ECDICT的释义、音标、例句或音频。

语义分类保存于`../semantic.json`。独立词可按语境置于同组，该分组不表示共同词源。science词族只保留science与scientific，research、experiment、theory改归独立词；innovation与invent不因语义相近而归为同一词族。

修改原稿后，重新生成内容并运行校对报告。若修改例句文字，须重新制作对应音频并复核，不得只沿用旧WAV。校对清单位于`../reports/card-audit.tsv`，记录词条、层级、目录、分组、来源标签和缺项。

校审工作台通过npm run editorial启动。署名、六项核对结果与依据保存到../reviews.json，数据库及发行检查分别见../../public/lexicon.sqlite与../reports/release.json。应用1.0开发版使用独立内容修订0.5.0和课程范围0.5.0。

完整来源与待裁定范围见../reports/official-scope.md。212个变体单元和原文观察需先核对，再决定展示与成卡方式，不把机械展开直接视为正确义项。
