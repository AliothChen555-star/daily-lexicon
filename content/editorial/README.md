本次内容由Codex辅助编写；运行环境未提供可归档的精确模型版本，记录为未提供，不虚构模型标识。编辑批次为`editorial-0.2-20261104`。没有将自动编写或结构检查通过的内容标为人工审核通过。

音标采用美音参考写法；功能词同时列出常见强读、弱读。live、use、house、frequent、coordinate、legitimate等同形异音或词性相关读音，在生成工具中明确主词性读音，并在词形栏提示其他读法。完整人工校听仍待进行。

基础、四级、六级标签各100词，只是试制分层，并非官方收录结论。来源候选名单之外的试用词在`../reports/scope.md`公开列出；正式词库收录前须裁定。拼写和分级候选与词卡正文分开管理，未复制ECDICT的释义、音标、例句或音频。

语义分类保存于`../semantic.json`。独立词可以按语境置于同组，该分组不表示共同词源，词卡中也不把同组其他词显示为派生关系。
