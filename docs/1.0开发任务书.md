# 词汇日报1.0开发任务书

状态：正式版开发中。应用构建1.0.0-dev.3，内容修订0.5.0，课程范围0.5.0。更新日期：2026年11月9日。

## 产品目标

免费、全开源、可离线使用的PC＋安卓背词程序。默认每天30个课程词，到期复习另计。先按多层语义完整背一遍基础＋四级＋六级词，再按词根、现代词族或独立词完整背一遍，最后反复全量乱序。单词、音标、读音、搭配、双语例句和翻译齐全。保留报纸式阅读界面。

本阶段不加入题库、语法课程、广告或收费接口，不建立必须登录的服务。

## 版本与完成标准

开发构建使用1.0.0-dev.N；候选发行使用1.0.0-rc.N；正式发行使用1.0.0。开发阶段结束不等于正式发行验收完成。应用版本、内容正文修订和课程范围分别编号，避免改正文或升级程序时重置学习课程。

正式发行必须满足：范围逐词核对并留有依据；必学词全部成卡；差异与特殊词裁定；每张卡有当前有效的六项人工校审；原稿、数据库、客户端快照、音频一致；Windows安装升级与安卓真机验收；长期签名、源码许可和下载产物检查。检查由release:check统一输出，缺项阻止正式交付打包。

## M1已落地的生产流程

原稿TSV与语义目录 → 内容生成 → 逐卡和音频校验 → SQLite与客户端快照 → 本机校审 → 六项签名记录 → 变更后重审 → 正式发行检查。

SQLite保存候选词、来源、正式卡、搭配、例句、词形、主题／场景／概念、构词组和校审记录。候选词与已制词卡分表，待制词不会变成可学习空卡。原有卡片的稳定标识与旧课程顺序保留。客户端目前使用同版本JSON离线快照，学习档案继续独立使用IndexedDB；尚未将个人学习存储迁入SQLite。

校审记录包含署名、时间、核对依据、六项结果和词卡指纹。指纹覆盖正文、原稿、归组、语义位置、固定来源和实际音频哈希。任何变化均使旧通过记录失效；需要修改的意见与历史通过记录同时保留，不覆盖历史。校审工作台仅本机访问，写入有来源与会话校验，学习档案不被读取或修改。

新增批次与构词组可由文件注册，主题不再限制为30词；编辑批次可追溯。历史课程保留词目快照，每日配额不因应用升级或正文修订重新发放。

## M2范围与资料规则

已读取[考试院原始大纲](https://cet.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf)，完成PDF21–149页的版面提取及独立文字序列对齐，保留物理行、附列形式、星号与页码。记录5,377个物理词目行、2,519个附列单元格；与原书公布的5,418／2,551计数分别保存，不强行混用口径。

当前机械展开为8,014个去重拼写，合并3,722个基础参考词形成8,375个待裁定目标。旧参考来源独有714词保留检索；212个变体单元、84个同形分列拼写、可疑原文和扩展词仍需裁定。没有将机械提取标为人工验收通过。详见[官方范围报告](../content/reports/official-scope.md)。

核对时保留来源版本、原始校验值、原拼写和所有级别标签；去重键与展示拼写分离。单列规则派生、不规则词形、缩写、短语和专名。每项纳入／排除需署名和依据；旧扩展词被排除出必学范围时，需先完成归档迁移，保留其历史学习事件与笔记。

只采用明确允许再分发的正文、例句和音频。当前ECDICT只用拼写及标签，释义、音标、例句与音频不由其搬入。新增外部资料必须先记录逐项许可与署名方式。原创或辅助编写内容进入草稿状态，人工校审后方可进入正式内容发行。

## M3每张词卡验收

- 拼写、稳定ID、词性与核心义项准确，覆盖常见用法；音标与选定主读音一致，异读有提示。
- 至少两个有效搭配、两条自然例句和对应翻译；例句包含目标词或已列明词形。
- 单词和两条例句均有可离线播放的发音，正文、音频与清单吻合。
- 三级语义目录有唯一主位置，可另设关联标签；词根、词族、独立词分开。不能因词义相近就推定同源。
- 意义、发音、英文用法、翻译、分类、来源许可六项均有当前有效的签名校审。

按语义场景分批，先制作有明确来源的直接词目；变体、附列形式与同形多义先核对规则，再扩充相应批次。分别统计待制、已制、通过和失效重审。当前参考层级为基础466、四级133、六级138、扩展13；完整人工通过仍为0。

## M4数据约束

课程覆盖与复习记忆分开；重复点击、重试、导入与跨天不重复记账。版本升级先保留恢复副本，迁移应幂等。后续同步必须处理离线并发、课程分叉、撤销与笔记冲突，不能静默覆盖。内容更新不能删除旧词的学习事件、收藏和笔记。

## M5平台验收

Windows验证解压使用、无开发环境启动、断网发音、重开续学、旧程序升级及备份恢复。安卓验证真实设备上的发音、触控、长时间后台切换、系统文件选择、分享导入、边距及不同WebView；编译与签名检查不替代真机验证。

正式安卓包使用可长期保存的发行密钥，密钥不得提交仓库。开发签名转正式签名的迁移需有备份恢复演练。Windows可提供免费便携包与公开校验值，不以购买签名服务为使用前提。
