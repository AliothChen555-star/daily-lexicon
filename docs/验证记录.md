# 词汇日报1.0.0-dev.3验证记录

验证日期：2026年11月9日。内容修订与课程范围均为0.5.0。上一批验证见 [dev.2记录](verification/v1.0.0-dev.2.md)。

## 词卡与发音

- 新增120个大纲直接列出的六级词目，分为学术阅读与论证、公共制度与法律、经济与经营、地理与环境变化。每词有两组双语搭配、两条双语例句和三段离线发音。120个选词的大纲记录ID与参考资料见 [0.5.0批次](../content/batches/0.5.0.json)。
- 当前750张卡、25个主题、71个场景、154个概念、205个构词或独立组。参考层级为基础466、四级133、六级138、扩展13。四个新主题按原有课程之后的顺序追加，原630张词卡正文、ID与语义顺序完全保留。
- 新增360段WAV，总数2250。对新批次使用en-us音素规则，针对excerpt、convict、affiliate、refund等词设定主读音。新增音频逐文件核对哈希、时长及非静音信号；旧1890段音频的清单与文件校验值保留。
- 词卡原稿、生成快照、SQLite、来源及离线音频一致。结构报告零缺项；SQLite的integrity_check和foreign_key_check通过。

## 课程、界面与平台

- 28项TypeScript、19项Python检查通过。全量模拟每日30词，完成750词语义轮后进入词根轮；词根、词族及独立词保持组内相邻，撤销末词、跨天、备份和旧档案仍通过回归验证。新增批次逐卡核对六级词目出处。
- 12项界面与实际Windows程序测试通过。新增六级词能按主题、场景和概念筛选，例句音频可播放，testify可跳到同源词testimony。验证小屏和平板无横向溢出；桌面、手机及校审工作台预览已更新。
- 实际dev.2便携程序写入评分、收藏和笔记后，dev.3在同一隔离档案续学。语义轮从630增到750，当天30词配额不重复发放。新版拦截网络请求时能播放新增refute音频，关闭重开仍可续学。
- Windows便携包和安卓开发包构建成功。Windows包版本为1.0.0-dev.3；安卓应用ID为org.dailylexicon.app，versionCode6，最低API26、目标API36。安卓v2签名有效，与dev.2开发签名一致。两端各2394个网页资源与最终构建逐文件一致，含当前SQLite和全部2250段音频。
